# Rohan Portfolio

Professional React + Vite portfolio website built with Tailwind CSS, Framer Motion, Lenis smooth scroll, custom cursor, scroll progress, 3D particle background, hover animations, project cards, resume section, and contact form UI.

## Open in Antigravity

1. Extract this ZIP.
2. Open Antigravity.
3. Click **Open Folder**.
4. Select the extracted `portfolio-main` folder.
5. Open terminal inside Antigravity.
6. Run:

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Main editable files

- `src/data/profile.js` — name, title, contact links, objective
- `src/data/projects.js` — project cards
- `src/data/skills.js` — skills section
- `src/data/education.js` — education timeline
- `src/data/experience.js` — experience/project timeline
- `src/data/certifications.js` — achievements section

## Notes

Old personal details from the original template were removed and replaced with Rohan's resume-based content.
